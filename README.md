## Project Overview
This system is designed to manage different aspects of event management. It supports different user roles, 
with each role having different functions and access permissions.

## Features
- Event Management
- Event Booking
- Ticket Management
- Session Scheduling
- Speaker Management
- Company Management
- User Management
- Role-Based Access
- User Registration and Login

## User Roles
The system provides different roles with different access permissions:

- **Admin** – Manages and oversees the system
- **Staff** – Handles event-related management and administrative tasks
- **Speaker** – Manages speaker information and related event sessions
- **User** – Browses events, makes bookings, and manages tickets
- **Company** – Manages company-related information and event participation

## Technologies Used
- Java
- Java Swing
- File Handling
- Object-Oriented Programming (OOP)

## How to Run
1. Clone this repository.

3. Open the project in a Java IDE.
